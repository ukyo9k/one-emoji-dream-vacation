## The entry

🏝️ — a desert island.

One emoji, nothing else, standing in for the trip of my dreams. A faraway
tropical island, palm tree and all: the postcard you can see before reading
a word. Not a plane, not a suitcase — those could be a business trip. An
island is a dream: nobody lives there, nobody works there, the whole trip
*is* the island.

## How it works

`main.py` writes exactly that one emoji to `/output/entry.txt`.
Deterministic — run it twice, get byte-identical output.

```sh
python3 main.py
cat /output/entry.txt   # 🏝️
```
